# Security policy

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/r-hural/evidence-echo/security/advisories/new),
not in a public issue. You will get an answer within a week. Only the latest release gets fixes.

What the plugin sends and stores (Anthropic, Voyage AI and Apify only with your keys; the web
sources you configure; PyPI for its pinned Python packages; local files in your data folder) is
listed in full in the
[repository's security policy](https://github.com/r-hural/evidence-echo/blob/main/SECURITY.md).
